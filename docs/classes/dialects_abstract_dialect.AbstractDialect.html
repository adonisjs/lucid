AbstractdropAllTables

  • dropAllTables(excludeTables?: string[], searchPath?: string[]): Promise<void>

    Drop all database tables.

    If database supports multiple schemas (like PostgreSQL), then the searchPath must be used to limit the results within the provided schemas.

    If "excludeTables" array is provided, then the mentioned tables must not be dropped.

    Parameters

    • OptionalexcludeTables: string[]
    • OptionalsearchPath: string[]

    Returns Promise<void>

    Example

    // drop all tables
    dialect.dropAllTables()

    // drop all tables within provided schemas
    dialect.dropAllTables([], ['public', 'reports'])

    // drop all tables except the excluded ones
    dialect.dropAllTables(['api_tokens'])

select

  • select(...columns: SelectExpressions[]): AbstractQueryBuilder

  • Select one or more columns from a given table. The columns can be represented as following values.

    • A string value represents the column name. "email".
    • A string value can also represent a column name + alias. "email as e".
    • AbstractQueryBuilder represents a subquery that must produce a single row. "SELECT (SELECT profiles.email from profiles LIMIT 1) from users";
    • Or a callback that receives a new query.

    Parameters

    • ...columns: SelectExpressions[]

    Returns AbstractQueryBuilder

    Example

    select('email')
    select('email as e')
    query().from('users').select(
      db
       .query()
       .from('profiles')
       .select('profiles.email')
       .where('users.id', '=', 'profiles.user_id')
       .limit(1)
    )

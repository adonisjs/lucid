select

  • select(...columns: SelectExpressions[]): this

    Select one or more columns from a given table. The columns can be represented as one of the following values.

    • A string value represents the column name. "email".
    • A string value can also represent a column name + alias. "email as e".
    • Use SelectExpressionBuilder to select columns from a subquery.
    • Use RawExpressionBuilder to select columns from raw a SQL expression.
    • Use RefExpressionBuilder to specify a formatted column name.
    • Or a callback that receives a new instance of the SelectExpressionBuilder

    Parameters

    • ...columns: SelectExpressions[]

    Returns this

    Example

    // Select email
    query.select('email')

    // Select email as e
    query.select('email as e')

    // Select from a sub-query
    query.from('users').select(
      db
       .query()
       .from('profiles')
       .select('profiles.email')
       .where('users.id', '=', 'profiles.user_id')
       .limit(1)
       .as('profile_email')
    )

    // Create subquery on the fly using a callback
    query.from('users').select((subquery) => {
      subquery
       .from('profiles')
       .select('profiles.email')
       .where('users.id', '=', 'profiles.user_id')
       .limit(1)
       .as('profile_email')
    })

    // Define aliases for all columns
    query.from('users').select({
      profile_email: db
         .query()
         .from('profiles')
         .select('profiles.email')
         .where('users.id', '=', 'profiles.user_id')
         .limit(1)
      user_id: 'id',
    })

    Inherited from SelectExpressionBuilder.select

  • where(...expression: WhereExpressionArguments): this

    Apply a where clause to the SQL query. The following column, operator and value combinations can be supplied.

    • Column name can be a string, RefExpressionBuilder, or the RawExpressionBuilder.
    • The operator must be a string.
    • The value can be a string, number, boolean, Date, buffer, RefExpressionBuilder, or the RawExpressionBuilder, SelectExpressionBuilder, or a callback function that receives an instance of the SelectExpressionBuilder.

    Parameters

    • ...expression: WhereExpressionArguments

    Returns this

    Example

    query.where('username', 'virk')
    query.where('username', '!=', 'virk')

    query.where('role', (q) => q.select('name').from('roles').where('id', roleId))
    query.where('lottery_number', client
       .raw('select ?? from ?? where ?? = ?', ['ticket_number', 'lotteries', 'status', 'won'])
       .wrap('(', ')')
    )

    query.where({
      username: 'virk',

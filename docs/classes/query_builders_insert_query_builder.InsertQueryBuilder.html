values

  • values(
        values: Record<string, any> | Record<string, any>[],
        options?: { includeTriggerModifications: boolean },
    ): this

    Define the values to insert into the table. Values must be an object or an array of objects. The values for object keys can be following

    • A literal value to insert to the database.
    • RefExpressionBuilder to point to an existing value.
    • SelectExpressionBuilder to define the value from a select query.
    • RawExpressionBuilder to define the value using a raw query.

    Parameters

    • values: Record<string, any> | Record<string, any>[]
    • Optionaloptions: { includeTriggerModifications: boolean }

    Returns this

    Example

    query.insertInto('users').values({
      first_name: 'Harminder',
      last_name: 'Virk',
      username: 'virk@adonisjs.com',
      email: 'virk@adonisjs.com',
      age: 35,
      role_id: (q: SelectExpressionBuilder) =>
        q.from('roles').select('id').where('is_default', true),
     })

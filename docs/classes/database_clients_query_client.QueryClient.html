Readonlymode

mode: "dual" | "write" | "read"

The mode in which the client should execute queries. In dual mode, the query client will send SELECT queries to the "read" connection and all other queries to the write connection.

In write mode, all queries will be sent to the write connection. Whereas, in read mode, write queries will be disallowed.

In case of transactions, the mode is always set to "write"
